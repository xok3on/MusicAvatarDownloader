# 🎵 MusicAvatarDownloader

Простое веб-приложение для поиска и скачивания обложек музыкальных треков.

## Возможности

- Поиск по названию и исполнителю
- Просмотр результатов в виде сетки
- Увеличение обложки при клике
- Скачивание в высоком разрешении

## ЯП
- Python - NiceGui

## Как использовать

1. Введи название трека и исполнителя
2. Нажми «Поиск»
3. Выбери нужную обложку
4. Скачай одним кликом
