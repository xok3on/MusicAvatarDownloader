# MusicAvatarDownloader
MusicAvatarDownloader — простой и красивый инструмент для поиска и скачивания обложек музыкальных треков. Введите название песни и исполнителя — получите качественную обложку в высоком разрешении одним нажатием. Идеально для музыкантов, диджеев, подкастеров и всех, кто оформляет плейлисты.
